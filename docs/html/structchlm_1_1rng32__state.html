Detailed Description

Complete serializable state of an rng32 generator.

Preserve both fields exactly when serializing a generator for replay, rollback, save/load, or deterministic debugging. Restoring a state with rng32::set_state reproduces the same future sequence without reseeding. This type is trivially copyable and contains no pointers or external state.
