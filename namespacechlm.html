◆ atan2()

float chlm::atan2 ( const float  y,
const float  x 
)
inlinenoexcept

Computes the quadrant-aware inverse tangent of y / x.

Uses a bounded-ratio polynomial and explicit IEEE 754 handling for signed zero and infinity. The maximum absolute error target is 6e-6.

For either sign of zero in y, positive x produces the same signed zero and negative x produces signed pi. A nonzero y with zero x produces signed half-pi. Infinite y produces signed half-pi when x is finite; infinite x produces signed zero or signed pi according to its sign. When both arguments are infinite, the result is signed pi/4 or signed 3pi/4 according to the quadrant. A NaN argument returns NaN.

Parameters
ySigned vertical component.
xSigned horizontal component.
Returns
Angle in radians in [-pi, pi].

◆ delta_angle()

constexpr float chlm::delta_angle ( const float  current,
const float  target 
)
constexprnoexcept

Computes the shortest signed angular displacement in radians.

Returns the signed rotation from current to target, reduced to the canonical interval (-pi, pi]. Positive results rotate toward increasing angles and negative results rotate toward decreasing angles. Because a half-turn has two equally short directions, an exact half-turn is always represented as positive pi.

Inputs may use any number of revolutions and need not already be wrapped. NaN or infinite inputs return NaN.

Parameters
currentStarting angle in radians.
targetTarget angle in radians.
Returns
Shortest signed angular displacement in (-pi, pi].

Applies frame-rate-independent exponential decay toward a target.

The decay is parameterized by half_life: after that many time units, half of the previous distance to target remains. ◆ smootherstep()

constexpr float chlm::smootherstep ( const float  edge_start,
const float  edge_end,
const float  value 
)
constexprnoexcept

Computes a clamped quintic Hermite transition between two edges.

Normalizes value between the edges, clamps the factor to [0, 1], and evaluates t^3 * (t * (6t - 15) + 10). The curve returns 0 at edge_start, 1 at edge_end, .5 at their midpoint, and has zero first and second derivatives at both endpoints. Compared with smoothstep(), this produces gentler acceleration into and out of the transition. A mirrored polynomial evaluation preserves numerical stability near both endpoints.

Values outside the edge interval are clamped rather than extrapolated. Reversed edges are supported and produce a descending transition as value increases. Equal edges behave as step(edge_start, value).

edge_endEdge corresponding to a result of 1.
valueValue at which to evaluate the transition.
Returns

◆ wrap()

constexpr float chlm::wrap ( const float  value,
const float  bound_a,

constexprnoexcept

Wraps a value into an explicitly bounded interval.

The result lies in the ascending half-open interval formed by the two bounds: [min(bound_a, bound_b), max(bound_a, bound_b)). Supplying bounds in reverse order therefore produces the same result as supplying them in ascending order. Values already inside the interval are returned unchanged.

Equal bounds define a zero-width interval and return bound_a for every value. NaN values or bounds propagate unless equal bounds have already resolved the result.

Parameters
valueValue to wrap.
bound_aFirst interval bound.
bound_bSecond interval bound.
Returns
Wrapped value in the ascending half-open interval, or bound_a if the interval is zero-width.
